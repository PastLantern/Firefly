## 1. OpenAI 大宕机 3.5 小时：一次常规数据库维护让 75% 请求失败

**时间**　2026年11月21日（美国西部时间 13\:48—17\:21，即北京时间 11 月 22 日 05\:48—09\:21）

**要点**　OpenAI 21 日遭遇今年最严重的一次宕机：持续 211 分钟，ChatGPT 与 API 的请求失败率峰值达 75%，免费与付费用户均受影响，波及对话补全、微调、嵌入、图像、音频、实时语音等几乎全部接口。OpenAI 当日在状态页发布了完整的事后报告：起因是针对 Primary API 服务所用 Postgres 数据库的一次计划维护，期间两个读副本同时故障；而该服务承载全站的用户认证与服务间认证，副本一垮，登录与请求随之瘫痪。OpenAI 称已暂停同类维护、调整数据库连接配置，并上线可按比例切走副本流量的开关。22 日上午状态页显示全部系统恢复正常。

**看点**　故障本身并不新奇——真正值得记的是它的形状：一个认证层面的单点依赖，让一次例行维护拖垮了整个产品。对依赖单一大模型厂商搭建智能体应用的团队，这是又一次提醒：关键链路需要跨厂商的降级预案，而不是事后复盘。OpenAI 当日即公开完整复盘，透明度高于多数基础设施厂商。

## 2. 黎曼猜想现第二份证明：人类手写 940 页，核查又过两关

**时间**　2026年11月20—22日

**要点**　黎曼猜想的剧情在同一天出现了第二份证明。据《自然》报道，就在 Anthropic 数学家 Levent Alpöge 20 日公布与 Claude 合作的 Lean 形式化证明数小时后，斯坦福大学数学家 Ravi Vakil 代为发布了另一份预印本：由斯坦福博士后 Alessandro Masullo 撰写、耗时约 12 年的 940 页纯人类证明，原计划打磨一年后再发表，因 Alpöge 的抢先发布而提前公开。Vakil 称该证明“全部由人类写成，没有 AI”。与此同时，Alpöge 证明的机器核查 22 日又过两关：MIT 的 Andrew Sutherland 的核查页面显示，第二个独立检查器 con-ron（con-leche 的 Rust 重写版）的比对模式确认五条定理全部成立，离线沙箱机独立重建的 61.57 GB 证明导出与公布版本字节一致。但仍未到终点：官方 lake comparator 的全量运行与 Lean 内核对完整导出的重放仍在进行中，克雷数学研究所仍将黎曼猜想列为未解。

**看点**　两份证明恰好构成一组对照：Alpöge 的版本已被机器核查、但无人读完；Masullo 的版本可供人阅读、但尚未经过机器核查，也被指出存在已知缺口。数学界的共识仍需时间，真正的看点在后面：谁先补上对方缺的那一环——人类可读的解释，或完整的形式化核查。

## 4. OpenRouter 下架三家推理服务商：AI 编程智能体泄露凭证致提示词外流

**时间**　2026年11月19—22日

**要点**　工业安全公司 Dragos 19 日公布一项金丝雀实验：7—11 月间向常用 AI 服务投放约 200 万条带有唯一链接与假凭证的提示词，追踪它们是否被盗用。随后三家服务商相继披露问题，其中 Together AI 21 日的公告最具警示性：一个 AI 编程智能体在开发公司公开 GitHub 仓库的过程中，把一枚凭证提交进了公开代码，该凭证可访问存有客户提示词样本的私有仓库；未授权方在凭证被撤销前的窗口期内下载了这些样本——样本来自 6—7 月间对 MiniMax M3、GLM-5.2、Kimi K2.6 模型的请求。下载者还从中搜索其他服务的凭证并逐一测试有效性，其中 5 个正是 Dragos 布下的金丝雀。Together AI 称暂无证据表明数据进一步外流，已把零数据留存设为新账户默认项。OpenRouter 22 日宣布下架三家服务商、将 125 个端点移出零数据留存适用范围，并通知可能受影响的客户；Dragos 与 OpenRouter 均未点名被下架的三家是否就是被发现的三家。

**看点**　这是第一起由 AI 编程智能体直接造成的大规模凭证泄露：不是配置失误，而是智能体把密钥写进了公开仓库。对用户最实际的提醒是：凡是曾把真实密钥、token 写进提示词的人，无论经由哪家推理服务商，都应立即轮换；同时检查所用服务是否默认零留存。对行业而言，“智能体写代码”正在制造新一类供应链风险，代码审查里查密钥这一步，恐怕要对智能体提交的内容格外严格。

## 5. 特斯拉 FSD v15 开始推送：实景视图上线，安全能力称提升 25 倍

**时间**　2026年11月21日（美国时间）开始推送

**要点**　特斯拉 21 日正式启动 FSD（完全自动驾驶）监督版 v15 推送，首批版本为 v15.0.1（软件版本 2026.38.6.11），先向美国新款 Model Y 等搭载 HW4（AI4）硬件的车型推送。特斯拉称新版本升级了端到端驾驶网络的每一个部分，安全关键场景的处理能力提升 25 倍，神经网络参数规模从约 10 亿扩大至约 100 亿，与 Robotaxi 车队运行同一套软件。最大亮点是全新的 Tesla Reality View：由车载 AI 实时生成的车辆上方虚拟视角，可呈现道路、建筑与行人，驾驶员能看到 FSD 正在规划的操作，甚至可点击画面引导车辆前往。马斯克称 12 月将向更多用户广泛推送。中国市场方面，特斯拉中国客服 22 日表示，正按国家法规要求推进辅助驾驶软件相关准备工作。

## 6. 微软 Copilot 全球上线 GPT-6.2 Sol：Astra 仅限部分入口

**时间**　2026年11月20日宣布

**要点**　微软 20 日宣布，OpenAI 的 GPT-6.2 Sol 与 GPT-6.2 Astra 开始进入 Microsoft Copilot。Sol 的覆盖面最广：符合条件的用户可在 Copilot Chat、Copilot Cowork、Copilot Studio 以及 Word、Excel、PowerPoint 中的 Copilot 里全球陆续用上。Astra 则收窄得多：仅在 Cowork 与 Studio 向全部符合条件的用户开放，在 Copilot Chat 与 Office 应用里只对 Frontier 早期体验计划成员开放。价格是分流的直接原因：Sol 的 API 价为每百万 token 输入 2 美元、输出 10 美元，Astra 为输入 8 美元、输出 40 美元。管理员需在 Microsoft 365 管理中心开启相关设置，Astra 的访问还依赖 OpenAI 子处理器的开关。

**看点**　这是 GPT-6.2 发布后最大的一次分发：微软把便宜的 Sol 铺到全员日常办公，把贵的 Astra 留给重型任务与先锋用户。对国内出海团队与微软 365 企业用户，升级是无感的——模型选择器里多出的 Sol 会成为默认的主力，Astra 则要看组织是否加入 Frontier 或开通按量计费。

**来源**　[Windows Forum](https://windowsforum.com/news/microsoft-copilot-adds-gpt-6-2-sol-and-astra-availability-billing-and-admin-controls.453493/)、[Microsoft Copilot 博客](https://techcommunity.microsoft.com/category/microsoft-copilot)

## 7. 腾讯 Hy4 正式开源（补录）：770B 旗舰模型，混元系列全量开放

**时间**　2026年11月20日

**要点**　腾讯混元团队 20 日宣布 Hy4 大模型正式开源，权重已在 GitHub、Hugging Face、ModelScope 与 GitCode 四个平台同步上线。Hy4 采用 MoE 混合专家架构，总参数 770B、每 token 激活 49B，上下文窗口 100 万 token，原生支持文本、图像与视频多模态输入。至此混元 LLM 系列完成全部开源，覆盖 Hy3、Hy4 及其 preview 与 flash 版本。Hy4 采用 Apache 2.0 协议，允许商业使用与修改；腾讯同步发布了系统卡片，披露网络安全与生物安全等维度的评估结果。同期开放的轻量版 Hy4 flash 总参数 224B、每 token 激活 12B，API 价格大幅低于 Hy4。

**看点**　这是目前开源权重中规模最大的旗舰模型之一：770B 的体量意味着自托管门槛不低（FP8 检查点约 770GB，官方建议 8 卡并行），但 Apache 2.0 协议与 vLLM、SGLang 的官方支持让有算力集群的团队可以直接部署。对国内开发者，Hy4 与 Kimi、DeepSeek 的开源旗舰同场竞技，选型的关键不再是参数量，而是各自在智能体与长上下文任务上的实测表现。

## 8. 谷歌 Genie 4 上线 Gemini API（补录）：世界模型按秒计费

**时间**　2026年11月19日

**要点**　谷歌 19 日把交互式世界模型 Genie 4 接入 Gemini API 与 Google AI Studio，开发者可用文本、参考图或两者结合生成一个可实时探索的世界：720p、24fps 的连续画面配立体声音频，支持键盘移动、视角控制与中途追加文本指令。计价方式罕见地按秒算：视频输出每帧 240 个 token、每秒 5760 个 token，折合约 0.10 美元/秒，即每分钟约 6 美元；单会话上限 120 秒，且谷歌文档提示画面连贯性在前 45—90 秒最强。Genie 4 仅限付费 API 密钥使用，不支持免费层、批量 API 与上下文缓存。

**看点**　世界模型从研究演示变成了有价目表的开发工具：按秒计费意味着“开着世界”的每一秒都在烧钱，适合做交互体验原型、空间概念可视化与机器人训练数据，而非长时间运行的服务。对国内开发者，接入需付费 Gemini API 密钥；更值得关注的是定价信号——实时生成式视频的成本已可按秒核算，下一代游戏与仿真原型的账本可以开始算了。

## 9. 前 DeepSeek 作者开源个人 Agent Linger（补录）：12GB 显卡跑 125B 模型

**时间**　2026年11月19日宣布

**要点**　前 DeepSeek-VL 项目负责人张博（Tony Zhang）19 日公布了新创业项目 Linger：一个跑在个人电脑上的开源个人 AI Agent，定位是“生活在你电脑上的专属 Agent”。Linger 本地读取邮件、日历与聊天记录，每晚自动整理成个人知识库；在长期对话记忆基准 LoCoMo 上准确率达 95%。核心技术是自研的 PolyStrata MoE 推理引擎：把专家权重分层存放在显存、内存与 SSD 间动态调度，官方数据显示 125B 参数的 Qwen3.8-Flash-Next 在一块 12GB 的 RTX 3060 上可达 45.5 tokens/秒，且数据不出本机、零 token 费用。项目已在 GitHub 开源。

**看点**　个人 Agent 的路线正在分叉：当同行都在做手机 App，Linger 押注电脑——因为邮件、日历与文件本来就在电脑上。12GB 显卡跑 125B 模型若属实，意味着本地大模型的门槛被大幅拉低；但注意两点：45.5 tok/s 与 LoCoMo 95% 均为官方自测数据，尚无第三方复核；且 2-bit 量化权重约 39GB，首次加载等待时间较长。适合喜欢折腾本地部署的用户先行试用。
