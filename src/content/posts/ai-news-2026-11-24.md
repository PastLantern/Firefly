## 1. 黄仁勋 11 天后复任英伟达 CEO：股价早盘一度涨约 33%

![芯片特写](https://images.unsplash.com/photo-1591799264318-7e6ef8ddb7ea?w=1200&q=80&fm=webp)

*芯片特写。图片来源：Unsplash*

**时间**　2026年11月23日（美国时间）

**要点**　英伟达董事会宣布，即刻起恢复黄仁勋总裁兼首席执行官及董事职务，投票一致通过；距其 11 月 12 日因婚外情（其中一位据称是中国间谍）辞职仅 11 天。董事会称，在与黄仁勋多次沟通并征求美国政府高层意见后，认为其复任不存在国家安全风险；特朗普在 Truth Social 发文欢迎。由独立董事组成的调查委员会仍将继续调查，董事会同时新设国家安全与出口管制委员会，并着手招聘首席合规官。消息出炉后英伟达股价早盘一度涨约 33%，纳指涨 6%、标普 500 涨 4%，收复上周五的大跌。

**看点**　11 天内“辞职—复任”的反转，凸显黄仁勋对英伟达的不可替代性，也暴露董事会在危机处理上的摇摆：上周财报电话会上董事长还说“无意恢复黄仁勋的职务”。短期看，AI 板块情绪被重新点燃；中长期看，调查尚未结案、合规整改在途，股价能否站稳要看调查结论与下一份财报。

**来源**　[路透社](https://www.reuters.com/technology/nvidia-reinstates-jensen-huang-ceo-2026-11-23/)、[华尔街日报](https://www.wsj.com/articles/nvidia-board-reinstates-jensen-huang-as-ceo-a6b49914)

## 2. 智谱 GLM-5.4 发布：750B Loop Transformer，Coding Plan 全量开放

![代码屏幕](https://images.unsplash.com/photo-1555949963-aa79dcee981c?w=1200&q=80&fm=webp)

*代码屏幕。图片来源：Unsplash*

**时间**　2026年11月23日晚

**要点**　智谱正式发布新一代大模型 GLM-5.4，首次采用 Loop Transformer 架构：对基座进行 28 层两轮循环深度推演，以 750B 级参数量达到比肩 3T 级模型的智能水平（官方称）。模型从传统 Coding 走向“泛 Coding”，把代码生成能力延伸至更广泛的场景，并支持与第三方建模软件联动。即日起向 GLM Coding Plan 全量用户开放，同步上线 ZCode、Trae、WorkBuddy、Qoder 等主流编码平台；Coding Plan V2/V3 及团队版用户的 GLM-5.4 使用额度提升至 1.5 倍。API 接口将在完成安全评估后对外开放，模型权重也计划以负责任的方式开源。

**看点**　“循环加深换智能”是国产大模型的又一条架构路线，与 DeepSeek 的路线形成对照。先上 Coding Plan、API 与权重待安全评估的节奏，值得与 Kimi、Qwen 的开放策略一起看；对国内开发者，GLM-5.4 能否在真实编码任务上兑现“3T 级”说法，要等第三方实测。

**来源**　[证券时报（经同花顺转载）](https://news.10jqka.com.cn/20261123/c682125341.shtml)

## 3. Anthropic 发布 Claude Ship：三个智能体接管 PR 评审、修复与审批

**时间**　2026年11月23日

**要点**　Anthropic 推出 Claude Ship（beta），把 PR（拉取请求）流程交给三个智能体：已上线的 Code Review（快速、标准、深度三档审查），新加入的 PR Steward（处理失败的 CI 检查、合并冲突与评审意见，并直接提交修复）和 Claude Approvals（按团队写在仓库里的审批政策文件，批准符合条件的常规变更）。面向 Team 与 Enterprise 计划的 GitHub 项目，可用 Claude Code 里的 /ship 命令一键触发；符合条件的企业组织可申请 1 万—5 万美元推广额度。Anthropic 称，内部 Claude Code 团队 6—9 月使用后，合并的 PR 数量翻倍以上，被回滚的 PR 占比下降超 40%。

**看点**　编码智能体从“写代码”走到“合代码”：审批权交给模型是效率跃升，也是信任跃升。政策文件怎么写、出了问题谁担责，会成为企业落地的第一道坎；对国内团队，先看 GitHub 侧的接入节奏。

**来源**　[路透社](https://www.reuters.com/business/anthropic-launches-claude-ship-help-developers-ship-code-faster-2026-11-23/)、[9to5Mac](https://9to5mac.com/2026/11/23/anthropic-launches-new-claude-ship-feature-for-builders/)

## 4. OpenAI 首席科学家公开困惑度曲线：呼吁行业在 0.68—0.70 前设限

**时间**　2026年11月22日（美国时间；北京时间 11 月 23 日凌晨）

**要点**　OpenAI 首席科学家 Jakub Pachocki 发表《Perplexity and Intelligence》，首次公开内部预训练对数困惑度：GPT-3.5 约 0.99、GPT-4 约 0.91，近期模型已低于 0.8；约 0.76 的模型开始在开放数学问题上取得突破性成果。他预计在约 0.68—0.70 区间还会出现新的变革性能力，呼吁前沿实验室就困惑度等指标达成“共同上限”，在监测能力跟上之前不越过该区间。Sam Altman 在 X 上称这是 OpenAI“一段时间以来发表的最重要的东西”。文章未点名任何已同意的实验室，也未提出核查与执行机制；困惑度基于 OpenAI 内部代码数据集，跨实验室难以直接比较。

**看点**　这是 OpenAI 第一次把内部损失曲线摆上台面，等于给竞争对手一张公开的能力阶梯图；但“限速”主张本身没有约束力，真正的看点是其他实验室是否接招——以及 0.68—0.70 这个窗口是否会在 2027 年如期到来。

**来源**　[Tech Times](https://www.techtimes.com/articles/331307/20261123/openais-jakub-pachocki-proposes-ai-scaling-limits-scored-private-test-only-openai-can-run.htm)、[PYMNTS](https://www.pymnts.com/news/artificial-intelligence/2026/openai-pitches-perplexity-score-to-set-ai-safety-limits/)

## 5. Anthropic 企业前沿保障公开测试：零数据留存，数据存客户自己的云

**时间**　2026年11月23日

**要点**　Anthropic 把 Enterprise Frontier Safeguards（EFS）推向公开 beta。符合条件的企业使用 Claude 最强模型时，提示词与回复可存放在客户自己的云存储中、由客户持有加密密钥，Anthropic 不再留存副本，同时仍对其运行自动化滥用监测（每 15 分钟扫描一次，识别复杂网络攻击迹象）。这扭转了 Anthropic 今年 6 月宣布的“前沿模型数据在自有服务器保留 30 天”的政策，当时曾引发客户反弹。

**看点**　零留存加客户自控存储，是对企业客户数据主权诉求的直接回应。对国内出海与合规敏感行业，这降低了使用 Claude 最强模型的合规门槛；但 EFS 仅面向符合条件的企业，且最强模型仍须接受 Anthropic 的监测扫描。

**来源**　[The Big Ant](https://www.thebigant.com/)、[Emergent](https://emergent.sh/news/anthropic-zero-data-retention-policy-launches)

## 7. 自变量发布具身基础模型 WALL-OSS-1.0：真机零样本成功率 55.1%

![机器人](https://images.unsplash.com/photo-1485827404703-89b55fcc595e?w=1200&q=80&fm=webp)

*机器人。图片来源：Unsplash*

**时间**　2026年11月23日

**要点**　具身机器人企业自变量发布新一代具身基础模型 WALL-OSS-1.0，强调把预训练本身作为智能的来源，而非后续任务微调的起点。在主流榜单 RoboDojo 的仿真赛道中，WALL-OSS-1.0 位列单模型能力第一名，超过了使用 Astra、Opus 5.5 等模型的 Agent 策略；多种真机测试中，零样本成功率高达 55.1%，无需微调的分数比经过微调的 π0.5 还要高 70.8%。

**看点**　具身智能的竞争正在从“数据加微调”转向“预训练出通用能力”。榜单与真机数据均为官方口径，第三方复核前先看演示视频与开源情况。

## 8. DeepMind 用 Gemini 智能体团队优化量子电路：Lean 验证，最高提速 11.8 倍

**时间**　2026年11月23日

**要点**　Google DeepMind 让多组 Gemini 4 智能体分别攻关量子电路优化问题，全部改进经 Lean 形式化验证确认，每四小时开一次虚拟会议交流进展；成果包括融合收益最高 11.8 倍、arcsin 计算提速 290 倍，相关开源库已发布到 GitHub。

**看点**　这是“智能体团队加形式化验证”组合拳的又一次落地：Lean 充当裁判，智能体负责想办法。量子电路只是试验场，同一套流程有望复制到芯片设计、编译器优化等可验证的工程问题上。

## 10. GPT-6.2 Astra 在 Lean 中证明 Smoktunowicz 间隙定理：94 分钟，新证明路线

**时间**　2026年11月23日

**要点**　据 Vals AI 披露，GPT-6.2 Astra 成为首个在 Lean 中机器验证 Smoktunowicz 2006 年间隙定理的模型：用时 94 分钟，给出一条基于容量的新证明路线，在 Autoform-Hard 评测中获干净评分。

**看点**　继黎曼猜想形式化证明后，顶级模型在 Lean 中攻克数学定理的速度仍在加快；但“首个”与“新路线”均为评测方口径，证明细节与可复现性仍待学界复核。

**来源**　[ExplainX（AI News Today）](https://explainx.ai/news)
