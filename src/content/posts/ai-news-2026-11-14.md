## 1. 英伟达创始人黄仁勋辞职，CFO 科莱特·克雷斯临时代理 CEO

- **时间：** 2026年11月12日（英伟达公告；董事会11月11日接受辞呈）
- **要点：** 英伟达宣布，黄仁勋已辞去总裁、首席执行官及董事会成员职务，即刻生效，结束了其自1993年创立公司以来33年的掌舵期。首席财务官科莱特·克雷斯（Colette Kress）出任临时 CEO，同时保留 CFO 职务；董事哈维·C·琼斯（Harvey C. Jones）出任公司首任董事长。公司在公告与向美国证监会提交的 8-K 文件中均未说明辞职原因。消息公布后，英伟达股价11月12日开盘一度跌约13%，收盘跌幅收窄至4.34%，报166.19美元。公司维持11月17日发布2027财年第三季度财报的计划不变。
- **看点：** 这是全球 AI 算力龙头33年来首次换帅，事发背景是董事会11月8日启动的独立调查：此前有报道称黄仁勋与新加坡云服务商 Megaspeed 高管黄爱玲（Alice Huang）的关系，美国情报官员怀疑后者为中国从事间谍活动；11月11日《纽约时报》又报道黄仁勋与一名向其汇报的英伟达高管存在第二段婚外情，《华尔街日报》同日报道董事会正准备将其免职。对用户短期无直接影响；对行业，英伟达的接班人选与11月17日财报电话会将成为下一个焦点。需注意：辞职本身并不证实存在安全漏洞、出口管制违规或职场行为的调查结论，董事会调查结果尚未公布。
- **来源：** [USA Today](https://www.usatoday.com/story/tech/2026/11/12/jensen-huang-nvidia-ceo-resigns-affair-investigation/92734431007/)

## 2. 前 OpenAI 研究员发布“权重取证”报告：六款中国大模型现禁运 Blackwell 芯片痕迹（未经独立验证）

- **时间：** 2026年11月12—13日（报告发布；北京时间11月13日凌晨5:29相关帖子发出）
- **要点：** 前 OpenAI 研究员威尔·德普（Will DePue）以 Unemployment Labs 名义发布题为《顶级中国前沿 AI 模型带有受出口管制英伟达 Blackwell GPU 的指纹》的取证分析，称 DeepSeek-V4-Flash、DeepSeek-V4-Pro、Kimi K3、Kimi K3.1-Pro、MiniMax-M3、蚂蚁 Ling-3.1-flash 六款模型在公开权重中留下了 Blackwell 芯片的初始化数值痕迹，其中对 DeepSeek-V4-Flash 与 Kimi K3 还在真实 Blackwell 芯片上复现了匹配；同一批公司的更早模型则对应上一代 Hopper 芯片。报告自称对 V4-Flash 的证据是“结论性的”，对其余五款为“有力的”，并估计 Kimi K3 与 DeepSeek-V4-Pro 各需数千张 Blackwell 训练两到三个月，但作者承认对芯片数量估计“没有把握”。该说法随后被马斯克等人转述扩散。
- **看点：** 这是中美 AI 竞争与芯片出口管制议题上的一次重磅指控，若属实意味着禁运硬件仍在流入中国前沿实验室；但必须强调：所谓“法证级证据”迄今未经独立验证或同行评审，涉事的 DeepSeek、月之暗面、MiniMax、蚂蚁集团及英伟达均未公开回应。报告自身也明确写道：该方法只能识别生成初始权重的芯片，不能证明全部训练都在该芯片上完成，也无法说明芯片身处何地、如何获得，更“不是认定违反了法律”——Blackwell 系统完全可以在中国境外的数据中心租用。对用户无直接影响；对行业，该方法的可靠性与后续各方的回应值得持续观察。
- **来源：** [Pulse](https://pulse.adyog.com/briefs/lab-says-six-chinese-ai-models-show-signs-of-blackwell-chip)

## 3. 谷歌发布 Gemini 4 Hydrogen：面向日常编程与智能体的高效模型

- **时间：** 2026年11月12日（谷歌官方发布）
- **要点：** 谷歌推出 Gemini 4 家族的执行导向成员 Gemini 4 Hydrogen，主打速度与成本效率，面向日常编程与智能体工作流。模型通过 Google AI Studio、Gemini API、Gemini 应用、谷歌搜索及 Gemini for business 全线提供，定价为每百万 token 输入1.50美元、输出7.50美元，支持100万 token 上下文。同期推出的 Antigravity Orchestrator 可在同一会话中动态切换不同模型执行任务。第三方评测 Artificial Analysis 称其在智能指数默认高思考档得51分，略高于旗舰 Argon 的50分，任务完成速度较前代 Flash 提升约2.5倍。
- **看点：** 这是谷歌在 Gemini 4 系列中补上“效率层”的一步：旗舰模型负责最难的推理，Hydrogen 承接智能体每天大量重复的执行任务，成本与延迟更低。对开发者，可直接在 AI Studio 与 API 中试用，尤其适合把智能体工作流的日常步骤交给它；对普通用户，Gemini 应用与搜索中的响应有望更快、更便宜。需注意：评测分数与速度提升为第三方及谷歌自报数据，未经独立复现。
- **来源：** [谷歌官方博客](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen/)

## 4. OpenAI 推出 Daybreak 安全工具：AI 红队自动渗透测试，Defense Factory 起草修补代码

- **时间：** 2026年11月12日（OpenAI “Cyber at the Frontier”活动）
- **要点：** OpenAI 在 Daybreak 安全平台下推出两款企业安全产品：Daybreak Red Team（早期试用，需申请）由多个智能体组成，读取源代码与应用上下文后对 Web 应用做持续渗透测试、验证外部报告的漏洞是否真实可利用并测试修复效果；Daybreak Defense Factory（预览版，作为 ChatGPT 内插件提供给已有 Daybreak 权限的工作区）则由智能体扫描代码库、定位漏洞根因并起草可合并的修补代码，工程师审核通过后才能合并上线。两款产品基于 OpenAI 的网络安全专用模型 GPT-6 Cyber，可接入 Wiz、Snyk、Endor Labs 等现有安全工具的发现结果与 GitHub 仓库。两款产品均未公布定价。
- **看点：** 这是“AI 既当攻击者又当防御者”的产品化落地：渗透测试与打补丁这两个过去高度依赖人工的安全环节，开始由智能体成规模地承接。对安全与开发团队，Red Team 可用来持续验证暴露面，Defense Factory 可把修复周期从“发现—排期—动手”压缩为“审核—合并”；但补丁仍须人工把关，不能直接自动上线。对普通用户无直接变化。需注意：这是产品发布而非漏洞披露，相关能力数字（如某未发布模型在 ExploitGym 的得分）未见于官方产品页，不宜当作正式规格。
- **来源：** [Silicon Report](https://www.siliconreport.com/openai-introduces-daybreak-security-tools-to-test-and-fix-web-apps)

## 5. Anthropic 开放自托管 Claude Managed Agents 私测：整个智能体服务可跑在企业自己的服务器上

- **时间：** 2026年11月12日（Anthropic 发布）
- **要点：** Anthropic 开放自托管 Claude Managed Agents 私测，企业可在自己的云或本地机房运行整套 Managed Agents 服务，包括运行智能体循环的 cma-server、存放智能体会话历史的 PostgreSQL 16+ 数据库，以及智能体执行代码的沙箱与所用凭证。此前该服务完全跑在 Anthropic 的服务器上，5月仅开放了自托管沙箱。唯一不搬家的是模型本身：每次对 Claude 的调用仍发往客户自选的推理方，默认 Anthropic，也可选 Amazon Bedrock、谷歌云、微软 Foundry 或自有网关；Anthropic 称其无法远程访问客户的自托管服务器与日志。私测仅面向符合条件的组织，须通过客户团队申请，暂无公开定价与正式版时间表；部分托管版功能（如定时部署、webhook、Files API 等）在自托管版中暂缺。
- **看点：** 这是企业级智能体落地的关键一步：金融、医疗等对数据不出内网有硬性要求的行业，此前因“智能体与会话历史都在厂商手里”而难以采用长时运行的 Claude 智能体，现在合规门槛大幅降低。对相关企业，可联系 Anthropic 客户团队评估接入；但要权衡代价——版本升级、运维与安全更新均由客户自己负责，且模型调用仍会把对话内容发往所选推理方，并非完全离线。需注意：该版本仍处私测，Anthropic 明确表示不建议直接用于生产部署的某些场景，须按文档用 Helm 部署。
- **来源：** [CellCog](https://cellcog.ai/blog/claude-managed-agents-self-hosted/)

## 9. DeepMind 发布 AlphaGenome 2：能按细胞类型预测 DNA 变异的影响

- **时间：** 2026年11月11日（谷歌 DeepMind 发布）
- **要点：** 谷歌 DeepMind 发布新一代 DNA 序列模型 AlphaGenome 2，可针对特定人类细胞类型与细胞状态，预测 DNA 变异如何影响基因表达。模型基于超过1亿个单细胞图谱、覆盖68种组织的人类与小鼠数据训练，能结合研究者自己的单细胞实验数据定制预测条件。在 TenK10K 单细胞免疫数据集（28种细胞类型）上，AlphaGenome 2 在90%精确率下找回30%的疑似因果表达变异，而上一代模型微调后为16%，接近翻倍。模型即日起通过 AlphaGenome API 向非商业研究免费开放，商业研究为受邀预览。
- **看点：** 这是 AI 在生命科学领域的又一次重要进展：同一段 DNA 在不同细胞里“读法”不同，AlphaGenome 2 首次把“在哪个细胞里”作为预测条件，有望帮助科学家更快定位疾病的细胞驱动因素。对科研用户，可直接通过 API 试用；对普通用户无直接影响。需注意：相关论文为预印本、尚未经过同行评审，数字均为 DeepMind 自报；模型仅限研究使用，未获临床或诊断用途验证。
- **来源：** [DeepMind 官方博客](https://deepmind.google/blog/alphagenome-2-deciphering-how-cells-read-dna-to-better-understand-disease/)

## 10. 清华发布单细胞蛋白组基础模型 ProtCell，国产 GPU 完成全流程预训练复现

- **时间：** 2026年11月13日（财联社报道）
- **要点：** 清华大学自动化系江瑞课题组发布面向单细胞蛋白组的基础模型 ProtCell，汇集约3.8亿个细胞、98个公开数据集用于预训练与评估，可精准映射细胞状态、推断未被测到的蛋白表达，为药物研发与“虚拟细胞”构建提供底座。论文同时披露，团队在摩尔线程旗舰 AI 训推一体智算卡 MTT S5000 上完成了 ProtCell 的全流程预训练复现，主要定量评测指标与国际主流 GPU 平台的差异仅约0.2%。ProtCell 代码已在 GitHub 开源。
