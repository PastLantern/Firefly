## 1. 中国开源六连发：蚂蚁、腾讯、上海 AI Lab、商汤、阿里与英伟达 24 小时内连发六个模型

![屏幕上的代码](https://images.unsplash.com/photo-1555066931-4365d14bab8c?w=1200&q=80&fm=webp)

*屏幕上的代码。图片来源：Unsplash*

**时间**　2026年11月26–27日

**要点**　腾讯、蚂蚁、上海人工智能实验室、商汤、阿里五家中国团队加上英伟达，在 24 小时内一口气放出六个可下载的开源权重或服务。蚂蚁 Ling-3.2-air：总参数 1240 亿、每 token 激活 55 亿，原生支持文本、图像、视频混合输入，SWE-bench Pro 从上一代 26.40 升至 58.28，AutomationBench-AA 从 15.7% 跃至 61%。腾讯混元 DFly2：投机解码草稿模型，挂在 Hy4 flash 上，不改权重、不改输出，复用目标模型的 KV cache，长上下文场景最高提速 4.2 倍，智能体任务上比同配方 DSpark 快约 30%。上海 AI Lab Sage-Interaction：全双工语音交互，随时打断、平滑接话，语音响应时延 1.29 秒，双工交互质量 80.73 分，官方称居当前开闭源双工模型首位。商汤 SenseNova-RoboRSI-27B 正式版：RoboDojo 34.7 分，是 Preview 版 10.0 分的 3.47 倍，超过了 RoboDojo 官方团队测试的 GPT-6 Astra；Apache 2.0 协议，GitHub 与 Hugging Face 权重全放。阿里 Wan2.7-Image：生图编辑统一模型，主打印刷级文字渲染与 12 种语言，盲测中文生图超 GPT-Image1.5（厂商说法），API 已上架阿里云百炼。英伟达 Nemotron-Labs-Image-30B-A3B：总参 300 亿、每步激活约 3B，Mamba-2 状态空间层与注意力混搭、GRPO 强化训练，LongTextBench 与 GenEval 上领先部分对手，GenEval2 上仍落后 GPT Image2。

**看点**　开源发布从单点变成多赛道同日卡位：编程、推理加速、语音交互、机器人操作、生图五条线同时更新。对开发者最实在的是两点：专用任务自部署的性价比地板又降了一截（Ling-3.2-air 扛代码仓库修复、DFly2 白捡提速、RoboRSI-27B 直接能商用）；但所有评测分数均为厂商或基准官方口径，未经独立复核，选型前先拿自己的任务跑一遍。

**来源**　[AI 工具宝箱](https://www.aitoollab.cn/articles/open-source-six-releases-one-day-2026/)、[einkCN 11 月 27 日 AI 产品速览](https://einkcn.com/html/product_6b09a439f0db18495.html)

## 2. DeepSeek 灰度测试每轮 token 账单：对话仍免费，但成本第一次摆到用户面前

![数据仪表盘](https://images.unsplash.com/photo-1551288049-bebda4e38f71?w=1200&q=80&fm=webp)

*数据仪表盘。图片来源：Unsplash*

**时间**　2026年11月26日起灰度测试，11月27日多家媒体报道（QbitAI 当日实测验证）

**要点**　DeepSeek 在网页与 App 端灰度测试“每轮消耗额度”显示：每轮对话结束后，回复下方出现硬币图标，点开可看到本轮消耗的 token 数与按 API 闲时价估算的成本，分缓存命中输入、未命中输入、输出三类。示例一轮对话消耗约 19.8 万 token：输入约 19.7 万，其中缓存命中约 18.5 万（0.02 元/百万 token）、未命中约 1.2 万（1 元/百万 token），输出 1470 个 token（4 元/百万 token），合计约 0.0215 元。费率与 DeepSeek-V4.1-Flash 的 API 闲时价一致。个人对话目前仍然免费，DeepSeek 未宣布任何付费计划；此前代码中被发现的“Coding Plan”相关内容也未获官方确认，“即将推出付费编程套餐”只是根据代码的推测，不能当作已确认事实。此前 DeepSeek 已以算力不足为由限制过长对话。

**看点**　免费产品第一次把成本账单摆到用户面前：单轮对话九成输入靠缓存、真正贵的是未命中缓存的那一小部分。结合算力紧张的背景，这个“账单”更像是在给用户做成本教育，而非收费预告；但“要收费了”是过度解读，官方什么都没宣布。值得留意的是另一面：按 OpenRouter 数据，DeepSeek-V4.1-Flash 在该平台的周调用量已达 59.2 万亿 token，为平台最高。

**来源**　[Phemex News](https://phemex.com/news/article/deepseek-graytests-feature-displaying-token-costs-per-conversation-104939)、[Blockoala](https://blockoala.com/index.php/2026/11/27/deepseek-shows-token-costs-for-each-chat-turn-but-conversations-remain-free/)、[ALFW](http://alfw.ai/article/deepseek-per-turn-meter-free-chat-cost/)

## 3. 腾讯 Hy3D 3.6 发布：200 万面、8K PBR，3D 生成开始进生产管线

![白色 3D 抽象渲染](https://images.unsplash.com/photo-1618005182384-a83a8bd57fbe?w=1200&q=80&fm=webp)

*白色 3D 抽象渲染。图片来源：Unsplash*

**时间**　2026年11月27日

**要点**　腾讯混元 Hy3D 3.6 正式发布：文本或图像输入，生成最高 200 万面的高精度几何（上一代 3.1 默认目标为 50 万面）、最高 8K 分辨率的 PBR 材质贴图，输出水密网格，支持 OBJ、GLB、FBX、STL、USDZ 等格式。面向游戏、工业设计与数字孪生场景，API 已上线腾讯云，接入 Miora 创意智能体、游戏资产生成平台 LAP 与影视 AI 平台 WorkRally；普通用户每天可免费体验 5 次。与过去世代不同，3.6 目前以云端 API 为主，截至 11 月 27 日在 Hugging Face 的腾讯官方账号下未确认有权重公开。

**看点**　3D 生成的卖点从“能看”变成了“能进生产管线”：面数与贴图分辨率双双摸到影视级门槛，生成资产可直接进入重拓扑、烘焙等后续环节。想本地部署的开发者先别等权重，先走 API 试效果。

## 4. 瑞士确认首批 AI 智能体攻击：5 起中有 4 起成功入侵，3 起针对关键基础设施

![电路板特写](https://images.unsplash.com/photo-1550751827-4bd374c3f58b?w=1200&q=60&fm=webp)

*电路板特写。图片来源：Unsplash*

**时间**　2026年11月24日（瑞士联邦网络安全办公室通报）；11月26日（局长接受 SRF 采访披露细节）

**要点**　瑞士联邦网络安全办公室（BACS）下属的国家网络安全中心（NCSC）确认，该国首次出现由 AI 智能体实施的网络攻击：共 5 起，其中 3 起针对关键基础设施运营方（电力、饮用水、电信等至少两个行业），5 起中有 4 起成功入侵受害者系统；其中针对关键基础设施的 3 起有 2 起得手，未造成重大服务中断。攻击者身份、受害者与具体工具均未公布。攻击使用所谓“智能体进攻框架”，自主寻找弱点、挑选攻击工具、评估结果并规划下一步，主要利用弱口令与已知软件漏洞。BACS 称网上可自由获取的此类智能体数量自 10 月以来几乎翻倍，通报中点名的 ARTEX 与 CyberStrikeAI 只是举例，并非确认用于这 5 起攻击。BACS 建议企业 24 小时内安装面向互联网系统的关键更新。

**看点**　与微软 11 月 25 日披露 ARTEX 被六个黑客组织使用的报告呼应（见昨日第 5 条），AI 攻击框架从“有人在用”变成了“已攻破关键基础设施”。防御重点仍是基础卫生：弱口令、未打补丁、暴露面过大——5 起攻击没有一起用到未知漏洞。

**来源**　[瑞士联邦网络安全办公室](https://www.bacs.admin.ch/en/26-ki-agenten-1-en)、[The Hacker News](http://thehackernews.com/2026/11/switzerland-confirms-ai-assisted.html)

## 5. 谷歌 Workspace 智能体强制走 MCP：2027 年 2 月 1 日起执行，Gmail 发送受限

**时间**　2026年11月24日（谷歌 Workspace 与 Google Cloud 博客宣布）

**要点**　谷歌宣布 Workspace MCP 服务器（覆盖 Gmail、Drive、Docs、Sheets、Slides、Calendar、Chat、Tasks）与 Workspace CLI 正式 GA；新版《Workspace AI Tools Addendum》要求 AI 智能体或相关工具改走 MCP 服务器或 CLI，不再直接调用 REST API，技术执行从 2027 年 2 月 1 日起，届时仍直接调 REST 的智能体将被限制在 Standard 级配额；Scaled 级用量从 2027 年 4 月 1 日起计费。Gmail MCP 服务器目前可搜索、读取邮件与创建草稿，发送、回复、转发等操作仅限合作伙伴接入；11 月 26–27 日的第三方核查中，发送功能的开放程度说法不一，以官方文档为准。

**看点**　智能体接企业数据的“官方通道”定了，但门槛也来了：约十周迁移窗口、用量计费、Gmail 发送受限。自研智能体接 Workspace 的团队现在就该排期改造；对普通用户，这意味着以后让 AI 代发邮件可能要多一次人工确认。

**来源**　[Google Workspace 博客](https://workspace.google.com/blog/product-announcements/built-for-trust-and-control-new-ai-agent-protections-and-developer-tools-in-google-workspace)、[Google Cloud 博客](https://cloud.google.com/blog/products/identity-security/deploying-agents-safely-in-your-enterprise)

## 6. Claude artifacts 可装为 Mac 与 Windows 桌面应用：beta 上线，三级权限、最高可完全访问电脑

**时间**　2026年11月24日（Anthropic 发布说明；11月25日多家媒体报道）

**要点**　Anthropic 上线“Install as app”beta：Claude Desktop 6.28899.0 及以上版本可把 artifact 通过标题菜单、右键菜单或分享菜单安装为 Mac 或 Windows 独立应用，自带图标与窗口，无需打包签名或另配 API key；覆盖 Free、Pro、Max、Ultra、Team 与 Enterprise 全部套餐（企业版须管理员手动开启）。权限分三级：默认仅限浏览器能力；可申请通知、全局快捷键与窗口置顶；最高“完全访问此电脑”可运行程序、读写与删除文件，且 Anthropic 明确表示安装前不审核这些应用。已安装应用须联网并保持登录 Claude 才能打开；Docs、Slides、Sheets 等模板与旧版 artifact 暂不支持；HIPAA 配置的组织不可用。

**看点**　Claude 从聊天框变成“个人软件工厂”：用一句话造的计时器、看板、文件工具可以直接进 Dock 或开始菜单。但“完全访问”权限加不审核，装别人分享的应用前要三思——它本质上是没经过应用商店审查的可执行程序。

*黑板上的数学公式。图片来源：Unsplash*

## 8. GPT-6 Astra 参与量子引力预印本：约 4 亿 token，复现黑洞熵与爱因斯坦方程

**时间**　2026年11月25日（arXiv 上线，18\:58 UTC；北京时间 11 月 26 日 02\:58）

**要点**　斯坦福物理学家 Venkatesa Chandrasekaran（亦在 OpenAI 任职）发表 54 页正文加附录的预印本《An algebraic quantization of gravity from the null cone》，提出在光锥上量子化四维真空广义相对论的方案：给出引力子对产生与湮灭振幅的有限闭式表达，复现贝肯斯坦–霍金黑洞熵及其对数修正，并在一圈水平下得到半经典爱因斯坦方程。致谢称，多项计算与证明是在与 GPT-6 Astra 数月协作中完成的，耗用约 4 亿 token（OpenAI 提供算力）。单作者，未经同行评议；理论只覆盖真空情形，不含物质场。

**看点**　继黎曼证明、VP≠VNP、矩阵乘法之后，AI 参与的数学与物理大声称又添一篇。但这是一份“提议”而非“定论”：专家核查需要数周到数月，而且理论本身只处理真空，别把它当成量子引力已被解决。

## 9. Anthropic 用 Claude 智能体把 Messages API 从 Python 迁到 Rust：CPU 降约 70%

**时间**　2026年11月25日（Anthropic 工程博客）

**要点**　Anthropic 披露 Claude 智能体如何把 Messages API——Claude API、Claude Code、Cowork 背后的最高流量入口——从 Python 迁移到 Rust：Claude 一周写出核心请求路径的初版，到 2026 年 5 月超过 80% 的合并代码出自 Claude；公开流量 2026 年 9 月已切到 Rust，全程不停机。每请求 CPU 降约 70%、内存降超 80%、Claude Code 请求的中位首 token 时间快约 20%。难点不是写代码而是验等价性：用线上 Python 服务当“标准答案”，影子流量比对、指纹与回放；4 月时真实流量匹配率仅约 24%，8 月升至 99.6%。

**看点**　这是迄今最完整的“智能体主导生产级迁移”案例。Anthropic 的结论值得抄：生成变便宜之后，验证才是瓶颈——迁移花了五个月，大头都在证明新旧版本行为一致。

**来源**　[Anthropic 工程博客](https://www.anthropic.com/research/migrating-api-to-rust)、[Think Facility](https://www.thinkfacility.com/blog/anthropic-claude-rewrote-messages-api-in-rust/)
