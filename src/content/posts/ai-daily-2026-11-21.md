本期时间范围为 2026-11-17 至 2026-11-19，收录上期推送之后在 arXiv 新发表的大模型论文。筛选标准：优先选 cs.AI、cs.CL、cs.LG、cs.CV 四个分类下与大模型后训练、推理、智能体、数据、架构、多模态、效率和评估安全直接相关的论文，按九大板块分配，共 30 篇，均与往期推送去重。需要说明的是，11 月 20 日发表的论文在推送时尚未在 arXiv API 中上线，故未收入本期，将顺延到下期覆盖。

本期后训练板块包含 2 篇 OPD（在线策略蒸馏）相关论文，其中 1 篇是 OPD 目标函数的理论分析，另 1 篇把 OPD 推广到了黑盒教师场景。

## 一、后训练

### 1. 交流式在线策略蒸馏：让黑盒教师通过对话教会学生做长程任务

- **原标题**：Communicative On-Policy Distillation: Distilling Black-Box Teacher Capabilities through Communication for Long-Horizon Tasks
- **发表日期**：2026-11-18
- **链接**：[arXiv:2611.23673](https://arxiv.org/abs/2611.23673)
- **核心创新**：传统 OPD 需要教师的 logits，但黑盒模型不暴露 logits；COPD 改用自然语言交流作为蒸馏媒介，学生自主决定何时向教师提问，成功的师生互动再作为特权参考，与任务奖励 RL 联合训练学生。
- **值得看**：把 OPD 从白盒教师推广到 GPT、Claude 这类黑盒教师，在 CAMG-II 上达到最强黑盒 OPD 基线的 2.46 倍增益，且学到的能力能泛化到 Terminal-Bench 2.1 与 SWE-Bench Pro V2。做 Agent 蒸馏的团队可以直接参考这条路线。

### 2. 在线策略蒸馏到底该蒸馏哪些 token、按什么顺序、多快？一项理论分析

- **原标题**：Which Tokens, in What Order, and How Fast? A Theoretical Analysis of On-Policy Distillation Objectives
- **发表日期**：2026-11-17
- **链接**：[arXiv:2611.23397](https://arxiv.org/abs/2611.23397)
- **核心创新**：首次系统分析 OPD 目标函数的选择：序列级 OPD 存在“未来一致性偏差”，会先拟合靠后的 token，甚至在靠前位置偏好教师认为不可能的 token；而散度选择决定优化难度，正向 KL 的目标 landscape 良好，反向 KL 等 f-散度在学生与教师相距甚远时也可能梯度消失。
- **值得看**：OPD 已是后训练标配，但目标函数多凭经验选；这篇给出了“序列级还是 token 级、用什么散度”的理论依据，调 OPD 超参前值得先读。

### 3. 自主后训练：让同一个模型成为更好的老师

- **原标题**：AutoMaster: Autonomous Post-Training by Making the Same Model a Better Teacher
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26510](https://arxiv.org/abs/2611.26510)
- **核心创新**：提出 Skill-FT，用自然语言“技能”在教师采样时抑制不良习惯、激发有效行为，再用所得轨迹微调目标模型；AutoMaster 让一个 LLM 智能体自主完成轨迹分析、技能设计、数据筛选与反馈迭代，教师、任务池、数据量和 SFT 方法都不变，只改变教师的行为质量。
- **值得看**：在终端、搜索和软件工程任务上比普通 SFT 高 1.42–8.99 个百分点。启示是后训练的瓶颈不一定在数据量，而在教师轨迹的行为质量，适合做 SFT 数据管线的团队参考。

### 4. 扩散模型的 RL 后训练本质上是激活转向

- **原标题**：RL Post-Training in Diffusion Transformers Is Activation Steering
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26627](https://arxiv.org/abs/2611.26627)
- **核心创新**：用一组与输入无关的固定转向向量加在冻结基座模型的 block 输出上，参数量只有 RL 微调 LoRA 的 1/65，却能恢复 6 个 RL 微调图像模型 90.0%–96.3% 的奖励增益；从零初始化、用在线 RL 直接训练这些向量，在文本渲染和人类偏好上甚至超过基于权重的 RL。
- **值得看**：对“RL 后训练到底学到了什么”给出了出人意料的简洁答案：大部分增益只是一个常数偏移，把预训练生成器推向它本来就会算的东西。做文生图、视频生成后训练的人必读。

## 二、推理

### 5. 固定预算 RLVR 会把测试时扩展能力“内化”掉

- **原标题**：Budget Internalization: Fixed-Budget RLVR Trades Test-Time Scaling for In-Budget Accuracy
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26172](https://arxiv.org/abs/2611.26172)
- **核心创新**：发现 RLVR 训练时的固定 rollout 上限会被模型“内化”为行为约束：训后模型在预算内更准，但超过预算后准确率不再提升、甚至低于基座模型；在 Qwen3.5-4B、Gemma4、Nemotron 等多个模型和数学、科学、代码任务上都成立，且 SFT 截断轨迹也能复现该效应，说明根源是长度截断式后训练而非 RL 本身。
- **值得看**：直接关系到推理模型“给更长思考时间是否还有用”这个实际问题；训推理模型时只盯预算内分数会付出隐性代价，预算设置需要重新权衡。

### 6. 用离轨策略挖掘强制 GRPO 保持推理多样性

- **原标题**：ROAM-GRPO: Enforcing Reasoning Diversity in GRPO via Routed Off-mode Approach Mining
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.25926](https://arxiv.org/abs/2611.25926)
- **核心创新**：针对 SFT+RLVR 导致策略坍缩为单一低多样性模式的问题，把训练中已解出的题目分流到“离轨”通道，提示模型给出不同的解题策略，经 LLM 评判验证逻辑有效性与差异性后自蒸馏回策略，从而在 GRPO 内激励探索不同推理策略。
- **值得看**：在 MATH lvl5 千题子集上训练 Qwen3.5-2B，pass@16 峰值提升 4.7%，输出多样性提升约 1.5–2 倍。关心 pass@k 和推理多样性的团队可直接借鉴。

### 7. 用最小编辑教大模型按指令推理

- **原标题**：Training LLMs to Follow Reasoning Instructions with Minimal Edits
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26342](https://arxiv.org/abs/2611.26342)
- **核心创新**：提出基于编辑的训练框架：对模型自己采样的推理轨迹，由编辑器定位首个失败点并给出最小替换片段，只对这些编辑片段做监督，既不像全轨迹 SFT 那样过度约束输出分布，也不像轨迹级 RL 那样信用分配粗糙；可离线也可在线使用。
- **值得看**：在 Qwen3-32B 与 ReasonIF 基准上，推理指令遵循度显著提升，同时基本保留了非目标任务的能力。适合需要模型“按指定方式思考”的场景，如结构化推理、合规推理。

### 8. 从推理教师蒸馏出的快速、校准良好的决策模型

- **原标题**：GLiDE: A Fast, Calibrated Decision Model Distilled from Reasoning Teachers
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26509](https://arxiv.org/abs/2611.26509)
- **核心创新**：决策模型只需一次前向就给每个候选答案打分，无需生成文本或中间推理；GLiDE 基于 Qwen 混合语言模型，解除全注意力层的因果掩码以实现上下文、问题与候选答案的双向交互，并用多教师软目标蒸馏（含推理教师）加渐进式后训练把推理能力迁移进单次推理，0.4B–27B 五个尺寸均位于性能-参数帕累托前沿。
- **值得看**：与本期关注的决策模型（Decisions API）路线直接相关：27B 版本在隐藏测试集得分 73.37，期望校准误差约 2%，单卡中位延迟 92.9 毫秒。需要“快且知道自己有多确定”的打分器时，这是目前最完整的开源路线参考。

## 三、Agent 与工具

### 9. 用共享决策模型引导小型深度研究智能体

- **原标题**：Seer: Guiding Small Deep-Research Agents with Shared Decision Models
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26423](https://arxiv.org/abs/2611.26423)
- **核心创新**：把智能体的“提议动作”与“预测后果、评估价值”分开：离线训练一个工具响应模拟器和一个价值估计器，推理时只执行被选中的动作，丢弃的候选不产生真实工具调用；两个模型跨智能体复用，无需针对每个智能体再训练。
- **值得看**：Qwen3.5-4B 的 GAIA 准确率从 13.6% 提升到 41.7%，Qwen3.5-9B 从 22.3% 提升到 50.5%。想在本地小模型上跑深度研究智能体、又不想为每次试错都付真实工具调用成本的场景很适用。

### 10. 智能体该记住多少？来自自蒸馏记忆的部署经验

- **原标题**：How Much Should an Agent Remember? Deployment Lessons from Self-Distilled Memory for LLM Agents
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26361](https://arxiv.org/abs/2611.26361)
- **核心创新**：从智能体自身轨迹中挖掘 1–3 条短“教训”，再合并成带支持度的“指南”，推理时注入全部或精选子集；核心发现是“该记多少”取决于模型本身而非记忆：强模型随指南增多持续变好，弱模型用精选小子集反而更好；论文还坦白记录了多个部署翻车案例。
- **值得看**：已落地于 IBM CUGA 智能体与 watsonx Orchestrate 平台，附带开源的 altk-evolve 库。做 Agent 记忆系统的人能直接抄作业，也能避开它踩过的坑。

### 11. 结构引导的记忆折叠，让智能体记忆更省

- **原标题**：MemFolder: Structure-Guided Memory Folding for Efficient Agent Memory Management
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26427](https://arxiv.org/abs/2611.26427)
- **核心创新**：用共享的记忆分组同时做两件事：RecordFolder 按实体与语义亲和度、时间链把兼容记录合并为更少的检索单元；ContextFolder 把组内原始记录编码成紧凑文本，并用可恢复性验证反馈修正编码；在三个文本记忆基准和两个多模态记忆基准上验证。
- **值得看**：记录数减半时仍保留 99.0% 的平均性能，超过最强基线 1.9 个百分点。长期智能体的记忆膨胀是普遍痛点，这篇给出了一套“先折叠、再压缩”的实用框架。

### 12. 运筹学算法设计的智能体挑战赛

- **原标题**：The FrontierOR Challenge: Agentic Algorithm Design for Operations Research
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26171](https://arxiv.org/abs/2611.26171)
- **核心创新**：指出 LLM 智能体能否设计出“在大规模实例上可扩展”的运筹算法仍是开放问题：最强模型在 FrontierOR 基准的一次性评估中，仅在 39% 的大规模实例上达到与 Gurobi 目标值 1% 以内且不更慢；挑战赛要求参赛者构建能同时为多个优化问题设计、测试、改进算法的智能体工作流，分主赛道与自托管赛道。
- **值得看**：把 Agent 评测从“写对代码”推向“设计出可扩展的算法”，覆盖路由、调度、网络设计等六类应用。关注 Agent 在科学与工程优化中真实能力的读者值得跟踪。

### 13. 面向电子表格智能体的接地交互与分阶段学习

- **原标题**：SheetAlign: Grounded Interaction and Stage-Isolated Learning for Spreadsheet Agents
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26069](https://arxiv.org/abs/2611.26069)
- **核心创新**：针对表格任务“既要懂任务推理、又要懂工作簿、还要选对操作接口”的三重难度，提出分阶段隔离的策略学习：按“在哪操作、改什么、怎么改”分阶段优化程序生成与审查，用编辑进度奖励训练，推理时以工作簿状态一致性筛选程序。
- **值得看**：仅靠接地任务接口就把 Qwen3-4B 在 SpreadsheetBench 上的准确率从 13.5% 提升到 29.2%，完整方法达到 32.8%。办公自动化 Agent 的落地参考，本地小模型也能用。

## 四、递归自我改进（RSI）

### 14. 自适应观测，让后训练自我改进走出平台期

- **原标题**：Sage-Evolve-Preview:Adaptive Observation for Post-Training Self-Improvement
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26132](https://arxiv.org/abs/2611.26132)
- **核心创新**：指出 RSI 循环的瓶颈不在训练而在观测：只看锚定基准的总分，早期涨分后很快陷入停滞与重复探索；提出自适应观测（AdaObs），在平台期细化诊断粒度、提高难度、加入相关任务，验证有效的增量再融合回训练，同时所有检查点仍用锚定基准评估。
- **值得看**：在 8 个独立优化的锚定任务上，平均分从 66.4 提升到 73.7（相同数据预算），并在独立的 PostTrainBench 上也有提升。做自我改进循环时，“看什么”与“怎么训”同样重要。

### 15. 给交互智能体练出“肌肉记忆”的系统一递归自我改进

- **原标题**：System-One RSI: Building Muscle Memory for Interactive Agents through Guided Practice
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26007](https://arxiv.org/abs/2611.26007)
- **核心创新**：用快慢双循环做 RSI：高频在线内环是 OODA（观察—判断—决策—行动）循环，决策模型直接输出结构化判断、经决策树转为限时动作，全程不调用推理模型；离线外环由推理智能体团队修订决策模型提示词与决策树、从交互记录提炼监督信号再训练部署，形成“外部肌肉记忆”。
- **值得看**：只用少量真实对局、无专家演示，贪吃蛇均分从 1.30 提到 7.35，《黑神话：悟空》战斗胜率从 0% 提到 66.7%。实时交互场景（游戏、机器人）中“快思考”的自我改进范式。

### 16. 别重采样，直接回放专家训练日志来合并 RL 专家

- **原标题**：Replay, Don't Resample: Off-Policy Consolidation of Long-Horizon RL Experts
- **发表日期**：2026-11-18
- **链接**：[arXiv:2611.24059](https://arxiv.org/abs/2611.24059)
- **核心创新**：多教师 OPD 合并 RL 专家成本高昂：学生要在每个环境里重新采样、专家要给每个 token 打分；MRPD 改为直接回放专家训练日志（带采样概率与奖励的轨迹，按专家学习顺序），在记录的前缀上重算策略梯度并蒸馏最终专家分布，不采样、不调用环境与奖励模型，合并成本仅为训练专家的约 1/7。
- **值得看**：在推理、搜索、SQL 三个长程智能体领域上超过在线 RL 基线与同专家 MOPD；且发现日志的顺序比数量与奖励更重要——专家训练日志是课程而非数据混合。做多专家合并的团队必读。

### 17. 用策略改进指导持续强化学习的回放

- **原标题**：Policy Improvement-Guided Replay for Continual Reinforcement Learning
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.25989](https://arxiv.org/abs/2611.25989)
- **核心创新**：从策略改进原理重新审视持续 RL：用性能差异引理把历史性能变化刻画为当前策略在历史任务分布上的期望优势，提出对比似然回放（CoLiR），按“最终任务策略在正确答案上的似然增益”与“初始策略在错误答案上的似然下降”之差挑选回放 prompt，KL 正则只约束回放 prompt。
- **值得看**：在三个 Qwen3-VL 尺寸与 MRCL 基准上取得最高的平均最终准确率与平均任务准确率，同时保持新任务性能。持续学习场景下“回放什么”有了原则性的选择标准。

## 五、数据

### 18. 大模型训练数据审计的统计框架

- **原标题**：A Statistical Framework for Training Data Auditing of Large Language Models
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26264](https://arxiv.org/abs/2611.26264)
- **核心创新**：把文档级成员推断、目标数据集整体审计与可疑子集识别统一进一个统计框架：用 Cauchy 组合聚合 chunk 级成员证据得到文档分数并校准 p 值，再经多重检验做整体评估与可疑文档识别，在给定可交换性条件下给出有限样本有效性、第一类错误控制与错误发现率控制。
- **值得看**：在 BookTection、Pile-arXiv、Cosmopedia、HealthCareMagic 等案例上验证。版权、隐私与基准污染审计都需要“某数据是否被训过”的可信答案，这篇给了带统计保证的方法。

### 19. 检索变好不是绑定变好：第一人称视频检索中的预训练暴露

- **原标题**：Better Retrieval, Not Better Binding: Pretraining Exposure in Egocentric Video Retrieval
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26120](https://arxiv.org/abs/2611.26120)
- **核心创新**：提出 Ego-ExBind 诊断协议，用 EgoClip 预训练语料建立暴露账本，区分“见过组合”“没见过组合”“没见过原子”三种切分，发现零样本检索提升与动词—名词对的预训练暴露正相关，而非真正的组合理解；仅替换推理时的暴露输入就能提升检索，说明很多“进步”只是预训练熟悉度。
- **值得看**：提醒所有人：视频-文本检索的分数提升要先排除暴露效应再谈理解能力。做多模态评测与数据配比的人应该读。

### 20. 拉美网络搜索：语言模型比搜索引擎更少引用本地新闻

- **原标题**：Web search in Latin America: language models use less local and diverse news than search engines
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.25955](https://arxiv.org/abs/2611.25955)
- **核心创新**：构建 1,901 起拉美时事、覆盖 9 国的数据集，向 3 个搜索引擎与 4 个语言模型提交 49,207 次查询，发现语言模型返回的新闻源多样性低于搜索引擎；对本地用户，搜索引擎本就只返回 41.3% 的本地新闻，语言模型还要再低 3.6–11.6 个百分点。
- **值得看**：用数据说明 LLM 搜索可能复制甚至放大地理信息层级，全球南方用户看到的本地新闻更少。做搜索产品与多语言评估时值得参考的实证研究，数据集已开源。

## 六、预训练与架构

### 21. Beam 模型技术报告：501B 参数 MoE，专为代码、推理与智能体优化

- **原标题**：Beam Model Technical Report
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26358](https://arxiv.org/abs/2611.26358)
- **核心创新**：501.3B 总参数、23.4B 激活参数的稀疏 MoE，在 23.8T token 上预训练，1M 上下文来自新颖的两阶段 midtraining；后训练是在 10.5K 块 GB300 GPU 上、4 周生成超 1 亿条 rollout 的大规模全异步 RL，据称是开放实验室迄今最大规模的 RL 训练之一；推理计算量比同级别模型少 3–4 倍。
- **值得看**：本期最值得读的模型报告之一：开源权重路线的推理能力新标尺，且 RL 算力继续加码仍未见平台期。关心开源模型天花板的人先读这篇。

### 22. 在 RoPE 注意力的隐藏维度上做稀疏化

- **原标题**：HiSA: Sparsifying the Hidden Dimension of RoPE Attention in LLMs
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26363](https://arxiv.org/abs/2611.26363)
- **核心创新**：注意力稀疏化以往都在 token 维度做文章，HiSA 改在隐藏（特征）维度稀疏：利用 RoPE 结构把 query、key 分解为可省略的部分，只算约 1/3 的 query-key 乘积；从头训练的模型性能不降反升，推理更快、显存更省，并已扩展到 FlashAttention-3 内核。
- **值得看**：开辟了注意力效率的新轴线，且机理分析表明稠密注意力本来就在压制 HiSA 丢掉的那部分分数。做推理加速与架构设计的人值得一读，代码已开源。

### 23. 循环扩散语言模型：用循环隐状态精炼代替更多去噪步

- **原标题**：dLoop: Looped Diffusion Language Models via Recurrent Latent Refinement
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26275](https://arxiv.org/abs/2611.26275)
- **核心创新**：扩散语言模型每步只有部分 token 可靠到能提交，现有加速方法只调置信度与提交策略；dLoop 把预训练扩散语言模型重组为 Prelude-Loop-Coda 结构，对同一部分掩码状态循环应用参数共享的中间 block，每次循环不推进去噪、只做更多隐层计算，让未提交位置的信息先充分交互再做提交决策。
- **值得看**：在 GSM8K、MATH、MBPP、HumanEval 上准确率全部最高或并列最高，且在相同 token/前向计算下优于 Fast-dLLM。扩散语言模型加速的新思路：算力花在“想清楚再提交”上。

## 七、多模态

### 24. 开源全模态视频理解新标杆 WeMM-Video

- **原标题**：WeMM-Video: Pushing the Frontiers of Open-Source Omni-Modal Video Understanding
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26409](https://arxiv.org/abs/2611.26409)
- **核心创新**：2B/4B/9B/35B-A3B 四个尺寸的中英双语全模态基础模型，统一文本、图像、音频与视频处理，支持“直接回答”与“逐步思考”双模式；约 1.2T token 多模态语料训练，后训练融合多教师 OPD、抗重复 MrDPO 与专家 RL；在 120 多个基准上评估，35B-A3B 创开源全模态视频理解新纪录。
- **值得看**：开源视频理解模型首次在全模态评测上大幅领先同类开源模型、逼近 Gemini-3.0-Flash，且 9B 模型超过更大的 Qwen3-Omni-30B。做视频理解应用的团队可以直接试用，模型与复现流程均已开源。

### 25. 在共享视觉空间里统一理解与生成

- **原标题**：HiUni: Harmonizing Understanding and Generation in Shared Visual Space
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26107](https://arxiv.org/abs/2611.26107)
- **核心创新**：统一多模态模型通常为理解与生成各用一套视觉表征或骨干计算；HiUni 直接复用预训练视觉语言模型的同一 ViT 与同一稠密 Transformer 骨干做两件事，任务特异性计算只放在输出侧，并用像素扩散头解决像素空间生成的优化难题、用轻量 HiGate 通路补回 ViT 语义抽象丢掉的细节。
- **值得看**：理解分数与原预训练 VLM 相当，生成与编辑性能也有竞争力，证明“一个稠密骨干同时做好理解与生成”是可行的。统一多模态架构的简洁路线，值得架构研究者关注。

### 26. 用自适应数据选择让“看图思考”更忠实

- **原标题**：Learning to Think with Images Faithfully via Adaptive Data Selection
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26199](https://arxiv.org/abs/2611.26199)
- **核心创新**：发现“看图思考”（TwI）模型准确率提升不等于工具使用忠实：模型常调用缩放工具却不依赖返回的放大区域；根源在训练数据——问题不缩放也能答对时，模型会学会无视证据；方法随模型能力演变自适应筛选数据，只训那些“正确缩放证据仍能帮模型答对”的问题，并辅以自适应奖励。
- **值得看**：视觉搜索基准上提升显著（V* +11.6%，HR-Bench 4K +7.9%、8K +9.4%），且在多模态幻觉基准上也优于同类方法。做视觉工具调用与可信推理的人必读：忠实度与准确率可以兼得，关键在数据。

## 八、效率与部署

### 27. 面向混合架构大模型的高效服务缓存系统

- **原标题**：TideCache: Efficient Hybrid LLM Serving with Transparent Cache Management and Layer-Wise Streaming
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26619](https://arxiv.org/abs/2611.26619)
- **核心创新**：混合架构（全局注意力层 + 有界状态层）已成开源权重模型主流，但两类层的缓存需求差异大；TideCache 在 CPU–GPU 超级芯片上用透明缓存池在固定虚拟地址后重分配物理页、用缓存流送器借有界状态层的计算间隙预取下一全局注意力层的前缀、用请求调度器按需选择常驻或流式执行。
- **值得看**：在 SGLang 上实现，于 GB300 与 GH200 的 7 组模型/平台配置上，智能体轮次完成量最高达 2.04 倍，P50 每 token 延迟降低 20%–59%。部署混合架构模型（如新一代开源 MoE）时值得参考。

### 28. 面向长程智能体任务的 3 比特以下量化

- **原标题**：NariQ: Sub-3-Bit Quantization for Long-Horizon Agentic Tasks
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26157](https://arxiv.org/abs/2611.26157)
- **核心创新**：指出低比特量化评测的盲区：现有方法用短网页文本校准、用困惑度评判，在 AIME 这类短任务上与 BF16 持平，但在长程智能体基准 DeepSWE 上最多只能完成 BF16 约 72% 的任务；NariQ 用格码量化，并在 BF16 模型于智能体对话中生成的 token 上校准，3.0 与 2.5 比特版本在 DeepSWE 与 Terminal Bench 上与 BF16 持平。
- **值得看**：据称是首个在 3 比特及以下与全精度持平的长程智能体任务量化方案，权重已以 GGUF 发布。想把 Agent 模型压到消费级硬件上部署的人可以直接用。

## 九、评估与安全

### 29. 谎言的几何：用知识与人格方向检测大模型欺骗

- **原标题**：The Geometry of Lies: Knowledge and Persona Directions for Detecting Deception in Large Language Models
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26545](https://arxiv.org/abs/2611.26545)
- **核心创新**：线性探针是最便宜的测谎器，但跨谎言类型迁移差；论文把已发表的人格库扩充为“明知故否认”的角色，在 70B 规模上测试人格方向；又提出知识方向（用“模型能答”与“没人能答”的问题加同一段否认脚本做对比），能在两到三个模型上把谎言与措辞相同的诚实否认分开；两者相加在四个模型上都优于同深度的监督探针。
- **值得看**：结论并不一味乐观：人格方向主要追踪措辞而非真实性，在 Qwen 上失效，知识方向在第四个模型上也不成立。对“能否用内部表征可靠测谎”这个安全问题给出了诚实的边界，值得评估与安全研究者细读。

### 30. 前沿模型只需一段文本就能认出作者是谁

- **原标题**：Frontier models need only one text to unmask its human or AI author
- **发表日期**：2026-11-19
- **链接**：[arXiv:2611.26216](https://arxiv.org/abs/2611.26216)
- **核心创新**：仅凭一段文本与一条简单零样本提示（无联网、工具、候选名单或写作样本），前沿模型就能回答“谁写的”：先判断人还是 AI，再判断出自哪个实验室，对人类作者常能直接点名；Claude Fable 5.2 正确认出 39% 的 2026 年 10–11 月公开同行评审作者（Nature 子集上 78%），认出 69% 的活跃 Reddit 用户名。
- **值得看**：准确率取决于作者写作在预训练数据中的暴露程度与推理投入；对网上发表过足够多文字的人，匿名威胁比普遍认为的更大，且防御手段有限。匿名评审、隐私保护相关的人必读。
